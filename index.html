¿Cómo se relaciona con la carrera?

Las semanas 1–12 preparan bases para Fundamentos de Programación. El repaso matemático acompaña Nivelación Matemática. Explicar cada solución también practica Habilidades de Comunicación. Las listas y diccionarios son una primera forma de organizar datos, antes de estudiar bases de datos.

Este es un plan preparatorio propuesto, no un programa oficial. Python es una elección para aprender; la malla no confirma el lenguaje del primer semestre. Cloud, Full Stack, desarrollo móvil y SQL quedan para una etapa posterior.

Recursos y primeros pasos

Para escribir y ejecutar Python, utiliza un computador. El teléfono sirve para ver videos y consultar la ruta. Empieza con la instalación y el entorno IDLE del curso principal. Instala Python solo desde python.org.

Python · freeCodeCamp Español es el curso principal. Lógica · MoureDev es un refuerzo opcional desde la semana 3: busca el tema de esa semana en sus capítulos; no necesitas terminarlo.

Matemáticas · Algebratic es la referencia seleccionada anteriormente. Sus capítulos y disponibilidad están pendientes de comprobación: busca el tema indicado, sin minutos asignados. Si no aparece, utiliza la búsqueda temática de cada semana.

Los enlaces del curso principal abren al inicio del segmento; debes detener el video al final indicado. Los desafíos son propuestas propias para practicar.
